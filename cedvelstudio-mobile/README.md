# Yigora 1.2.0 — pulsuz şəxsi server

Windows kompüterində Yigora serveri; Android isə kompüterə şəxsi WireGuard (və ya Tailscale) VPN bağlantısı vasitəsilə qoşulur. Google girişi, Firebase və pullu bulud xidməti yoxdur.

Android: http://10.13.13.1:8765 WireGuard nümunə ünvanıdır; real şəbəkənizdə uyğun adresi daxil edin. Kompüter, VPN və printer işləməlidir. Telefonun səlahiyyətləri Windows-dakı Cihazlar və icazələr bölməsində verilir.

Aylıq xərclər və şəxsə verilən pulun cəmi Windows serverində hesablanır və telefonda icazəyə uyğun göstərilir. APK Android 8.0+ və yeni loqo ilə yığılır.

# Yigora 1.0.0 — Android

A black-and-white Android launcher icon derived from the approved Yigora monogram, brand name on launcher and Android installation, Android 12+ splash, and native server connection UI.

Requires existing Yigora Windows backend and Tailscale private connectivity. The app does not collect data independently. It uses the Windows server to enforce 17 per-device permissions; unauthorized devices cannot print or edit.

The APK uses no Google OAuth integration; pairing is via a one-time code generated by the Windows administrator. Do not expose the Windows backend port publicly.
